# pi-strata-provder

为本地推理服务 Strata 提供自动模型发现和安全调优的 pi 扩展。

[English documentation](README.md) · [MIT 许可证](LICENSE)

> 包名按原定名称保留了 `provder` 拼写。当前通过代码托管仓库安装，尚未发布到软件包注册服务。

## 快速开始

1. 启动本地 Strata 服务，通常地址为 `http://127.0.0.1:8080/v1`。
2. 安装扩展：
   ```sh
   pi install git:github.com/Lxxyx/pi-strata-provder@v0.1.0
   ```
3. 启动 pi，输入 `/strata`，选择“Apply recommended Pi setup”。
4. 正常使用。扩展在启动、打开模型选择器以及刷新模型目录时获取最新元数据。

要求 pi 及其模型接口库至少为 1.0.4，运行环境至少为 Node 22.18。

默认提供商名称是 `local`，自动模型入口是 `local/strata-auto`。
切换本地实际模型后，不必修改默认模型标识。

## 服务地址和密钥在哪里设置

- `/strata`：打开菜单，配置服务地址、查看状态、刷新模型或应用推荐设置。
- `/login local`：使用 pi 原生认证流程保存真正的服务端密钥。
- 也可以通过 `STRATA_API_KEY` 环境变量提供密钥。
- 无认证的本地服务不需要填写密钥，默认占位值为 `strata-local`。

密钥优先使用 pi 的运行时或已保存凭据，然后使用环境变量、可选字面值，最后使用占位值。
占位密钥不会绕过服务端认证。遇到认证失败，扩展会引导设置正确密钥，不会显示用户填写的密钥，也不会反复弹窗。

Strata 服务端可通过启动参数 `--api-key`、服务进程的 `STRATA_API_KEY` 环境变量，或运行配置里的 `api_key` 启用认证。
启用后，模型列表和模型属性接口也需要认证。

默认仅监听本机回环地址。
如需监听局域网或通过隧道暴露，务必配置真实密钥并设置防火墙及加密传输。
不带密钥使用自定义主机名时，可能需要设置服务端 `allowed_hosts`。
pi 不是浏览器，无须为它开放浏览器跨域访问。

一般启动脚本使用 8080 端口；直接启动服务端程序而不指定端口时可能使用 8095。
以实际启动日志里的地址为准。

## 命令

| 命令 | 功能 |
| --- | --- |
| `/strata` | 管理菜单 |
| `/strata status` | 查看地址、认证要求、模型、上下文和刷新状态 |
| `/strata refresh` | 强制刷新模型 |
| `/strata url` | 修改地址并重新加载 |
| `/strata setup` | 应用推荐设置并重新加载 |
| `/strata key` | 查看密钥配置说明 |
| `/login local` | 保存密钥 |

推荐设置只修改本地模型的压缩预算和默认选择，不修改其他提供商、全局思考等级、工具、主题或包列表。
如果用户明确关闭了全局自动压缩，扩展尊重这一选择。

如果显著修改了服务端的上下文大小，再应用一次推荐设置即可自动计算新预算，不需要自己计算数字。
普通模型刷新不会静默改写 pi 设置。

## 自动发现和调优

扩展读取服务的模型列表、模型属性和健康接口，自动获取：
- 模型标识及别名；
- 实际运行上下文，而不是训练时宣传的上限；
- 图片输入能力；
- 聊天模板及思考控制方式；
- 服务端采样默认值和输出上限；
- 是否需要密钥。

元数据保存在 pi 原生的 `models-store.json` 中。
网络、认证或数据格式错误时保留上次成功的目录；成功返回空目录时会移除旧模型。
缓存按服务地址隔离，不会把另一个服务的目录套用到新地址。
完整聊天模板、密钥、会话内容和服务端模型文件路径不会写入模型缓存。

### 思考档位

Strata 的服务端会将“高”转换为模板需要的“超高”，因此使用原生推理强度请求参数，而不是错误地只打开模板开关。

| pi 档位 | 服务请求值 | 默认软思考预算 |
| --- | --- | --- |
| 关闭 | `none` | 0，同时关闭思考 |
| 低 | `low` | 1,024 |
| 中 | `medium` | 4,096 |
| 高 | `high` | 8,192 |

不支持或重复的档位会隐藏。
正数预算限制在输出预算的四分之三以内，为最终回答和工具调用留空间。
这是服务端支持的软预算，不是严格耗时保证。

自动模型入口在普通对话中沿用用户选择的思考等级。
压缩及分支摘要采用低档思考；如果模型不支持低档，则关闭思考，避免摘要任务浪费大量生成时间。
工具后续请求尽量留在同一实际模型上。

### 输出、采样和图片

- 输出默认不超过 16,384，也不超过实际上下文的四分之一。
- 服务端输出上限更小时，采用更小值。
- 服务端报告无限制输出时，客户端仍使用有限预算。
- 保留服务端明确配置的采样默认值，不凭模型名称随意设置温度。
- 图片默认最多 1,568 × 1,568，编码后最多 512 KiB，压缩质量为 80。
- 使用系统消息角色，不假设服务支持开发者角色、严格工具模式或通用思考预算字段。
- 不凭空声明缓存保活时间，也不增加不必要的保活推理。

这些是偏安全的预设，不是所有模型和显卡上的性能最优证明。

### 压缩设置

推荐设置按模型计算：
```text
预留空间 = 较小值（上下文的一半，较大值（输出预算 + 4096，上下文的四分之一））
保留近期历史 = 较小值（20000，上下文的四分之一）
```

实际上下文为 131,072、输出预算为 16,384 时：
- 预留 32,768；
- 保留约 20,000 的近期历史；
- 估算上下文超过 98,304 时触发普通阈值压缩。

Strata 可选的 `fit_max_tokens: true` 能将输出缩短到实际剩余空间。
这是额外保护，不能代替正确的压缩设置；扩展不会自动修改服务端配置。

## 可选配置文件

默认无须创建文件。高级配置位于：
```text
~/.pi/agent/strata-provider.json
```

支持：
- `PI_CODING_AGENT_DIR`：改变 pi 用户配置目录；
- `PI_STRATA_CONFIG`：指定插件配置文件；
- `PI_STRATA_BASE_URL`：覆盖服务地址。

参见 [示例配置](strata-provider.example.json) 和 [英文完整配置表](README.md#configuration)。
单个模型的覆盖配置使用精确模型标识作为键。
明确覆盖上下文、输出上限或能力时，需要自己承担与服务实际能力不匹配的风险；一般不需要设置这些覆盖。

可选兼容模式包括其他聊天模板服务器、奥拉玛及标准兼容服务。
本版本真实服务验收的对象是 Strata；其他模式仅有元数据单元测试，不能理解为同等程度的真实服务验证。

## 从手写模型配置迁移

备份 `models.json` 后，移除旧的 `providers.local` 配置块。
pi 会将手写配置覆盖到原生提供商上；旧配置可能把自动刷新的上下文和思考控制方式重新覆盖成过期值。

安装时不会擅自删除用户配置。
执行一次推荐设置，或者手动选中自动模型并保存为默认值即可。

## 测试

```sh
npm ci --ignore-scripts
npm run check
npm run test:e2e
```

常规检查包含类型检查和离线单元测试。
端到端测试连接已经启动、启用图片支持的真实 Strata 服务，使用临时 pi 配置和临时工作区，不碰正常会话文件。

覆盖实际推理、思考档位、工具调用、文件读写、图片、手动压缩后的记忆、自动压缩、取消恢复、目录缓存、认证恢复和实际命令行启动。
自动压缩通过临时降低阈值和填充测试文本触发，摘要仍由真实模型生成。
认证恢复通过临时回环代理执行密钥检查，再转发到真实服务；不伪造模型回答。
